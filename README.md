# ANIMASTER

Редактор анимации в браузере. Node.js 22+; внешние зависимости не нужны.

```sh
npm start
```

Готовый `index.html` содержит стили, логотип и код редактора внутри одного файла. Его можно открыть напрямую в обычном браузере без сервера и сети. В управляемом браузере прямой доступ к файлам может быть запрещён — тогда используйте `npm start`.

Исходный шаблон: `src/shell.html`. После изменения шаблона, CSS или JS выполните `npm run build`, чтобы обновить `index.html`. При `npm start` и `npm run dev` сборка выполняется автоматически; внешние пакеты не нужны.

Сервер запускается на порту 5173 (или `PORT`). Откройте его в браузере Chrome / Edge / Firefox. Файлы обрабатываются локально и не загружаются на внешний сервер.

## Работа

Новый проект: один прозрачный слой и один кадр. **Q** и **A** всегда вставляют новый кадр сразу после текущего, сдвигая следующие кадры вправо на всех слоях. Например, при 10 кадрах на позиции 5 новая позиция — 6, а кадров становится 11. Длину также можно изменить числом «Кадров» (без фиксированного предела).

- **1** — карандаш, **2** — ластик. Колесо над холстом меняет размер активной кисти / ластика от 1 до 500 px с шагом 3 px. Круг вокруг курсора показывает фактический диаметр мазка с учётом размера холста и масштаба выбранного слоя; он не попадает в экспорт. **3** — заливка, **4** — редактировать (перемещение, размер и поворот), **F** — дополнительная клавиша заливки, **M** — дополнительная клавиша редактирования, **K** — удалить выбранный цвет. Клавиши работают по физическому расположению, включая русскую раскладку; при вводе текста они не перехватываются.
- Меню **Форма кисти**: круг (по умолчанию), квадрат, спрей. Форма применяется также к ластику. Спрей распыляет точки, пока удерживается ЛКМ. **Разброс светлоты** (0–100%) делает отдельные участки рисунка светлее или темнее выбранного цвета; при 0% цвет неизменен. На ластик, заливку и кисть территорий этот ползунок не влияет.
- Палитра серого: RGB (255,255,255), (200,200,200), (100,100,100), (50,50,50), (0,0,0). Выбор меняет цвет рисования и заливки; произвольный цвет по-прежнему доступен слева. Параметры кисти сохраняются в проекте.
- Рисование, заливка и ластик меняют только текущий кадр выбранного слоя. Другие кадры не наследуют рисунок автоматически.
- **Q** вставляет ключевой кадр после текущего и копирует текущий рисунок в независимый холст выбранного слоя.
- **A** вставляет после текущего пустой промежуточный кадр. Его собственных рисунка и ключа нет. Между соседними ключами A-кадр интерполирует положение, масштаб обеих осей, поворот и прозрачность; разные рисунки плавно растворяются друг в друге. Без двух соседних ключей рисунок A-кадра прозрачен. Редактирование превращает его в отдельный ключ.
- **Delete** удаляет текущий кадр или выделенный диапазон, сдвигая следующие кадры влево на всех слоях. В проекте остаётся минимум один кадр. Видео и звук остаются непрерывными источниками с привязкой к времени N/FPS.
- **Shift+ЛКМ** выделяет диапазон кадров от последнего обычного щелчка. Копирование и удаление работают с выделенным диапазоном; Q/A вставляют один кадр после текущего. Рисование работает только на текущем кадре.
- **Пробел** создаёт слой, **Backspace** удаляет выбранный слой. Воспроизведение запускается и останавливается кнопкой ▶ на шкале времени.
- **C** копирует выделенные кадры, **V** вставляет их в выделение; при одном кадре назначения — начиная с текущего кадра выбранного слоя. Копируются рисунки, ключи и тип A-кадра; аудио и исходный видеофайл остаются на своём слое. Вставка заменяет содержимое кадров назначения; Z отменяет её.
- **Z** — отмена, **Y** — вернуть отменённое. Поддерживаются также Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z, Ctrl+C / Ctrl+V. История хранит до 20 последних изменений в текущей сессии.
- Стрелки — переход между кадрами, Shift+стрелки — выделение диапазона. Частота 1–240 FPS. Ползунок прилипает к 12, 24, 60 и 144 при приближении на 3 FPS; числом можно задать любое точное значение. Переключатель «Повтор» на шкале времени запускает анимацию с начала после последнего кадра, включая видео и звук. При включённом повторе конечные A-кадры плавно переходят от последнего ключа к первому ключевому кадру следующего цикла — по рисунку и всем трансформациям. Если перед первым ключом тоже есть A-кадры, переход продолжается через начало шкалы. С одним ключом A-кадры сохраняют его рисунок и параметры. Этот переход виден при выборе кадра, воспроизведении и экспорте. Настройка сохраняется в проекте; экспорт по-прежнему записывает один проход.
- В режиме **Редактировать** тяните слой для перемещения, боковые маркеры для независимой ширины, верхний / нижний — для независимой высоты, углы — для обеих осей, зелёный круг — для поворота вокруг центра слоя. В панели доступны отдельные поля «Ширина» и «Высота» (в процентах), а «Масштаб» меняет обе оси вместе. Предел масштаба 1000% снят: числовые поля и маркеры принимают большие значения. Кнопка замочка связывает значения ширины и высоты: при включении высота получает масштаб ширины, затем стороны изменяются одинаково при вводе чисел и перетаскивании. Замок сохраняется отдельно для каждого слоя в проекте; переключение можно отменить через Z/Y. Размеры обеих осей плавно интерполируются на A-кадрах. Маркеры автоматически размещаются внутри холста даже у увеличенного или смещённого слоя; при очень маленьком слое рамка управления увеличивается для удобства. Точные значения масштаба и угла доступны справа. Редактирование A-кадра превращает его в самостоятельный ключ. Полный оборот можно задать числом 360°; углы между ключами интерполируются как заданные числа.
- Кнопка **+** (или пробел) добавляет слой; стрелка поднимает слой; двойной щелчок по имени переименовывает его.
- Импорт PNG, JPG, WEBP, GIF, MP4, MP3. GIF импортируется статично. Поддержка видео и аудио зависит от кодеков браузера. Для MP4 шкала расширяется по формуле `ceil(длительность × FPS)`, без ограничения в 600 кадров. Без монтажа кадр с индексом N показывает видео в момент N/FPS, независимо от наличия ключа или типа A. Видео воспроизводится непрерывно; не декодируется целиком в картинки в памяти.
- **🎙 Записать звук** запрашивает разрешение браузера на микрофон. Повторное нажатие останавливает запись и добавляет отдельный звуковой слой (WAV), который сохраняется в `.animaster` и звучит при воспроизведении / экспорте WebM с начала проекта. Файлы не отправляются на сервер. Доступ к микрофону требует HTTPS или localhost. При отказе разрешите доступ в настройках сайта. Длительность записи не ограничена числом кадров.
- **Сохранить** открывает меню сохранения: «Сохранить в библиотеку» сохраняет текущий проект и превью; «Твои сохранения» открывает список всех проектов. В Windows это обычная папка, а в браузере — IndexedDB; очистка данных сайта удаляет браузерные сохранения. Автоматического сохранения нет.
- **↓ Проект** скачивает `.animaster` с рисунками, медиа, слоями, ключами и A-кадрами. **Открыть** восстанавливает скачанный файл. Этот же вариант доступен в меню «Сохранить».
- **↓ Анимация** открывает параметры видео. Нажмите «Создать видео · WebM», дождитесь окончания и нажмите **«↓ Скачать видео .webm»**. Перед скачиванием готовый результат можно просмотреть прямо в редакторе. Кнопка скачивания остаётся доступной для повторной загрузки до следующего экспорта / закрытия страницы.
- Экспорт PNG (текущий кадр) или WebM (анимация со звуком). Размеры 480×270, 960×540, 1920×1080. Качество меняет битрейт видео; PNG без потерь. При записи в реальном времени держите вкладку активной. Экспорт MP4 и анимированного GIF пока отсутствует.

При увеличении используется сглаживание высокого качества и плотность пикселей экрана. Неизменённые импортированные изображения рисуются из оригинала, без предварительного уменьшения до разрешения холста. Рисунки и отредактированные изображения остаются растровыми: увеличение не восстанавливает отсутствующие детали.

Значок `logo.svg` — SVG-интерпретация предоставленного рисунка, а не исходное изображение.

## Видео, карты и свободные углы (0.2.0)

- **Удаление фона у видео:** выберите видеослой, инструмент «Убрать фон» (K), нажмите на цвет внутри видео. Фильтр применяется ко всем кадрам непрерывного видео, включая A-кадры, и сохраняется в `.animaster`. Ползунок допуска меняет близость удаляемых оттенков. «Восстановить фон видео» отключает фильтр, Z/Y отменяют/возвращают изменение. Выбор цвета учитывает перемещение, масштаб, поворот и свободные углы слоя. Экспорт PNG/WebM использует тот же фильтр.
- **Шаблоны карт:** кнопка «Шаблоны карт» открывает мир, Европу и Африку. Карта добавляется как отдельный слой изображения, не заменяя текущий проект. Все три SVG встроены в HTML/EXE, поэтому интернет при использовании не нужен. Источник геометрии и лицензия — `assets/maps/README.md`.
- **Свободные углы:** в панели трансформации включите настройку, затем тяните оранжевые углы в режиме «Редактировать» (4). Углы меняют перспективную форму отдельно, а не масштаб всего слоя. Пересечение углов не допускается. На A-кадрах координаты углов интерполируются между ключами, включая переход через конец при включённом повторе. Остальные обычные кадры не меняются. Выключение режима сохраняет форму, но возвращает обычные маркеры масштабирования; «Сбросить углы на этом кадре» возвращает прямоугольник. Настройка, форма и ключи сохраняются в проекте.
- **Обучение:** кнопка в верхней панели открывает девять шагов: рисование, кадры, слои, углы, видео/карты, звук/скачивание. «Назад»/«Далее» переключают шаги; Escape или крестик закрывают окно. Клавиши редактирования не выполняются при открытом обучении.

## Выделение, Q*/A*, свои страны и языки (0.7.0)

- **V** вставляет во всё выделение. Один скопированный кадр заполняет выбранные кадры, последовательность повторяется по выделению. При одном кадре назначения по-прежнему вставляется весь скопированный блок. **Держите V**, выделяя новые кадры: вставка продолжается, одно удержание отменяется одним Z.
- **N** теперь превращает **все выбранные кадры, включая ключи с рисунками**, в A-кадры; прежнее содержимое выбранных ключей заменяется промежуточными значениями. Z возвращает его. Удержание N действует на вновь выделяемые кадры.
- Числовые трансформации и редактирование на холсте изменяют всю выбранную группу одним приращением, сохраняя относительные различия между кадрами. Это касается перемещения, масштаба сторон, поворота, прозрачности и свободных углов. Если деформация пересекает углы хотя бы одного кадра, группа сохраняет последнюю допустимую форму.
- На видео и звуке по умолчанию **все кадры A***, без создания массива на всю длительность источника. Изменения создают **Q*** на выбранных позициях, промежутки интерполируются. На видео анимируются трансформации; на звуке — громкость и питч. Исходные значения на концах клипа служат опорой, пока там нет Q*. Для непрерывного клипа через весь проект при повторе A* соединяет последний и первый Q*.
- Для звукового слоя панель рисования заменена **громкостью и питчем Q*/A***. Громкость ключа (0–200%) умножается на общую громкость клипа; питч задаётся в полутонах от −24 до +24. +12 удваивает частоту, −12 делит пополам, длительность не меняется. Независимый питч работает через AudioWorklet; прежняя галочка влияния скорости на питч остаётся отдельной настройкой клипа. Поддержаны просмотр, экспорт и сохранение. Выделять медиа можно на линейке или Shift+перетаскиванием по клипу.
- **Своя страна** в панели карты: введите имя и загрузите изображение флага. Оно нормализуется в PNG и хранится с проектом. Новая страна доступна кисти территорий, моря защищены; список сортируется по алфавиту языка интерфейса. Названия своих стран остаются пользовательским текстом.
- **Языки** выбираются сверху: русский, English, 中文, हिन्दी, Español, Français, العربية, বাংলা, Português, Bahasa Indonesia. Переводятся основные панели, действия, инструкции, обучение и стандартные названия стран. Выбор сохраняется на устройстве. Имена проектов, слоёв, свой текст и названия кастомных стран не переводятся автоматически.
- **+ у палитры** добавляет текущий цвет к серым оттенкам. Дополнительные цвета сохраняются на устройстве и в проекте. **Скорость колеса кисти** — 1–10×; по умолчанию 3× (три пикселя на шаг), как раньше.
- Удержание стрелок ускоряется **5 → 10 → 20 → 40 → 60 → 80 → 100 кадров/с** с секундными ступенями. Shift расширяет выделение; отпускание останавливает движение.

Проверяются групповая вставка/отмена, числовые и мышиные трансформации, Q*/A*, независимый питч в готовом видео, кастомные флаги/сохранения, сортировка во всех 10 языках, палитра и колесо. Отдельно проверен AudioWorklet в настольном Electron с локальным HTML.

## Монтаж видео и звука, управление слоями (0.6.0)

- У каждого слоя — кнопка перечёркнутого глаза (скрыть, сохранив данные), стрелки вверх/вниз и × (удалить). Они есть в списке справа и в названиях дорожек. Скрытый звук не воспроизводится и не экспортируется. Z/Y отменяют и возвращают изменения. Эффект шума остаётся над обычными слоями.
- Колесо над названиями дорожек или списком слоёв меняет масштаб шкалы **0,02×–1×**. При 0,02× на прежнем месте помещается в 50 раз больше кадров. Ползунок с числом масштаба доступен над шкалой. Позиции, FPS и длительность от масштабирования не меняются; при сильном уменьшении маркеры соседних кадров объединяются визуально. Колесо над содержимым дорожек прокручивает список.
- Звуковые дорожки показывают настоящую **форму громкости**, рассчитанную из декодированных отсчётов: светлая — пики, зелёная — RMS. При наведении показываются время и дБ. Учитываются обрезка, скорость и громкость. Если кодек не позволяет декодировать анализ, интерфейс не подставляет выдуманную волну.
- Видео и звук представлены клипами. **Тяните середину** для перемещения по времени, **края** — для обрезки. Исходник не изменяется: края можно раздвинуть обратно. Начало и конец также доступны числами в секундах; на сфокусированном крае стрелки изменяют обрезку на один кадр.
- Нажатие на клип или его слой открывает **громкость (0–200%)**, **скорость (0,25–4×)** и **«Скорость влияет на питч»**. С галочкой высота звука меняется вместе со скоростью; без галочки браузер сохраняет питч. До начала и после конца клипа видео прозрачно, звук выключен. Перемещение, обрезка, скорость, громкость и питч работают при просмотре, цикле и экспорте WebM и сохраняются в `.animaster`.
- Удерживайте **←/→**: сразу выполняется один шаг, затем 5 кадров/с, после секунды — 10, после двух — 20. Shift продолжает выделение. Отпускание или потеря фокуса останавливают переход.
- Удерживайте **N**, выделяя новые пустые кадры мышью или стрелками: они становятся A-кадрами на месте. В 0.7 преобразуются и нарисованные ключи (Z возвращает их). Одно удержание отменяется одним Z; отпускание N выключает режим.

Формат проекта остаётся совместимым: у старых видео/звука по умолчанию начало 0, весь исходник, скорость 1× и громкость 100%. Масштаб шкалы сохраняется с проектом. Набор тестов проверяет не только параметры, но и тишину до клипа, громкость и реальную частоту тона в экспортированном видео при обоих режимах питча.

## Деформация, длинные анимации и регионы (0.5.0)

- Убраны швы и белые треугольники: вместо независимо смешиваемых треугольников применяется непрерывное обратное перспективное преобразование. WebGL ускоряет отрисовку; при его отсутствии работает программный вариант с интерполяцией цветов с учётом прозрачности. Просмотр, A-кадры и экспорт используют один путь.
- Удалён фиксированный лимит кадров из вставки, копирования, импорта, записи звука и загрузки проектов. Длинная шкала создаёт только видимые ячейки; поле «К кадру» позволяет перейти к любой позиции. Практический объём проекта зависит от памяти устройства.
- Частота — **1–240 FPS**. Ползунок притягивается к **12, 24, 60, 144**, рядом есть кнопки этих значений. Числовое поле позволяет вводить точную частоту без притягивания. При экспорте частота задаёт таймер отрисовки; фактическая скорость записи зависит от устройства и кодека браузера.
- Добавлены **Северная Америка, Южная Америка, Азия и Евразия** со странами, флагами, годами и кистью территорий. Все семь карт доступны офлайн. Региональные данные воспроизводятся `python scripts/region-maps.py` из встроенной геометрии мира.

## Исправления кадров, рамки и территорий (0.4.0)

- **N** превращает выбранный пустой кадр (или пустые кадры выделенного диапазона) в A-кадр на прежней позиции. Длина анимации не меняется. Кадры с рисунками не стираются; Z/Y отменяют и возвращают преобразование. Q/A по-прежнему вставляют новые кадры после текущего.
- Рамка редактирования охватывает непрозрачные пиксели рисунка, текста или изображения. Пустой кадр не имеет рамки. При свободных углах деформируется область содержимого; внешняя отсечка удерживает рисунок внутри четырёхугольника. Маркеры за пределами холста имеют доступные ручки со связующими линиями, сама рамка остаётся на рисунке. Размер и поворот меняются относительно центра содержимого. A-кадры сохраняют плавный переход, в том числе к обычному ключу без деформации.
- На новых картах владельцы суши сохраняются отдельно от картинки. Флаг центрируется по каждой связной части территории, пересчитывается при расширении и потере земли. Для вогнутых территорий центр выбирается внутри страны. Моря защищены. Территории сохраняются вместе с проектом и поддерживают копирование ключей, удаление кадров и отмену.
- **Совместимость карт 0.3:** прежние растровые правки сохраняются. Поскольку старый файл не содержит владельцев захваченной земли, их нельзя однозначно восстановить из цветов флагов. Для полного автоматического центрирования после захватов добавьте новый шаблон карты в 0.4.

## Текст, карты и библиотека (0.3.0)

- **T** открывает поле текста около курсора на холсте. Внутри доступны шрифт, размер, цвет, цвет и толщина обводки. Ctrl+Enter применяет текст, Escape отменяет ввод. Текст добавляется самостоятельным слоем, который можно двигать и анимировать. Кнопка «Изменить текст» редактирует выбранный текстовый слой. Шрифты системные: Arial, Verdana, Georgia, Times New Roman, Courier New и sans-serif.
- Карты отображают SVG-флаги стран (встроенные офлайн). На выбранном слое карты рядом с кнопками начала/конца шкалы задаются **первый и последний год**; значение интерполируется по всем кадрам и рисуется в левом верхнем углу холста, в том числе при экспорте. Это числовая шкала: исторические границы и флаги автоматически не меняются.
- **Кисть территорий** находится в настройках выбранной карты. Выберите флаг в списке, затем рисуйте. Размер задаётся обычным ползунком кисти и колесом. Рисование ограничено контуром суши карты и не закрашивает море/океан. Изменения сохраняются на текущем кадре; Q копирует карту в следующий ключ. A-кадры используют переход между рисунками ключей.
- Шаблон **«Осветление шума»** добавляет верхний слой затемнения: 0 дБFS соответствует прозрачности, −100 дБFS — чёрному, промежуточные значения линейно меняют непрозрачность. Уровень оценивается по RMS звуковых дорожек. Для декодируемого аудио расчёт выполняется по отсчётам в момент кадра, одинаково в просмотре и экспорте; при отсутствии офлайн-декодера используется анализ воспроизведения. Тишина даёт чёрный слой. Чтобы рисовать под ним, временно скройте слой значком глаза. Новые обычные слои создаются под эффектом.
- При запуске появляется **«Твои сохранения»**. «Новая анимация» начинает новый проект; нажатие на карточку открывает сохранённый. На карточке — скомпонованный первый кадр, независимо от текущего кадра при сохранении.
- В Windows кнопка **«Сохранить» → «Сохранить в библиотеку»** записывает `.animaster`, PNG-превью и метаданные в `Документы/ANIMASTER/Анимации`. Повторное сохранение обновляет текущий проект по ID. В библиотеке есть кнопки открытия и выбора папки. При смене папки старые файлы остаются на прежнем месте.
- **«↓ Проект» и скачивание видео** в настольной версии сразу записывают файлы в системную папку «Загрузки». Если имя занято, добавляется номер. Скачивание не добавляет проект в библиотеку.
- В браузерной версии библиотека хранится в IndexedDB. Обычная папка и прямое управление «Загрузками» доступны в Windows-версии. Старое браузерное сохранение остаётся в списке; для него превью появится после пересохранения. Файлы старых версий можно открыть и сохранить в новую библиотеку.

SVG-флаги: flag-icons 7.6.0, MIT, © Panayiotis Lipiridis. Лицензия находится в `assets/flags/LICENSE` и включена в самодостаточный HTML и настольную сборку. Геометрия стран — Natural Earth (public domain).

## Проверка

```sh
npm run check
npm test
npm run test:ui
# После npx install-electron можно проверить настоящую папку и перезапуск:
node tests/desktop-smoke.cjs
```

Модульные тесты проверяют интерполяцию ключей и углов, обратные координаты перспективы, границы заливки, удаление цвета и операции кадров. Браузерные тесты (`tests/editor-browser.cjs`) проверяют движущееся видео с хромакеем, экспорт, углы, сохранение проектов, семь офлайн-карт и обучение. Для них нужен Chrome/Chromium; путь можно задать через `BROWSER_EXECUTABLE`. Тестовое видео `tests/fixtures/chroma-motion.mp4` создано локально: красный квадрат движется по зелёному фону. Редактор не использует облачные API или секреты.

## Версия для Windows (.exe)

Переносимая сборка Windows 10/11 x64: `dist/ANIMASTER-0.7.0-Windows.exe`. Запускается двойным щелчком и открывает редактор отдельным окном с иконкой ANIMASTER. Для готового EXE не нужны Node.js, браузер, сервер или установка зависимостей. Настройки и сохранение «в этом браузере» в настольной версии хранятся в профиле приложения пользователя; для переноса проекта на другой компьютер скачайте `.animaster`.

Сборка из исходников (Node.js 22.12+):

```sh
npm ci
npm run build:win
```

Команда собирает самодостаточный HTML и Windows EXE со встроенной иконкой. При первой сборке требуется сеть для загрузки Electron и упаковщика; версии инструментов закреплены в `package-lock.json`. Значок собирается из `assets/icon.ico` (размеры 16–256 px); значок окна — `assets/icon.png`. Исходный рисунок в проекте представлен SVG-интерпретацией.

Запуск настольной версии из исходников на текущей ОС:

```sh
npx install-electron
npm run desktop
```

Настольная оболочка использует Electron, изолированный контекст страницы и отключённый Node.js в редакторе. Диалоги сохранения выбирают путь на устройстве. Разрешён доступ редактора к микрофону, доступ к камере не запрашивается.

EXE собран в Linux; формат Windows x64, ресурсы значка и встроенные файлы проверены. Запуск настольного редактора и сохранение проекта проверены на Electron для Linux. Непосредственный запуск готового Windows EXE в этой среде не проверялся. Сборка не имеет цифровой подписи издателя.
