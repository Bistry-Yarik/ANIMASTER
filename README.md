# ANIMASTER

Редактор анимации в браузере. Node.js 22+; внешние зависимости не нужны.

```sh
npm start
```

Готовый `index.html` содержит стили, логотип и код редактора внутри одного файла. Его можно открыть напрямую в обычном браузере без сервера и сети. В управляемом браузере прямой доступ к файлам может быть запрещён — тогда используйте `npm start`.

Исходный шаблон: `src/shell.html`. После изменения шаблона, CSS или JS выполните `npm run build`, чтобы обновить `index.html`. При `npm start` и `npm run dev` сборка выполняется автоматически; внешние пакеты не нужны.

Сервер запускается на порту 5173 (или `PORT`). Откройте его в браузере Chrome / Edge / Firefox. Файлы обрабатываются локально и не загружаются на внешний сервер.

## Работа

Новый проект: один прозрачный слой и один кадр. **Q** и **A** всегда вставляют новый кадр сразу после текущего, сдвигая следующие кадры вправо на всех слоях. Например, при 10 кадрах на позиции 5 новая позиция — 6, а кадров становится 11. Длину также можно изменить числом «Кадров» (1–600).

- **1** — карандаш, **2** — ластик. Колесо над холстом меняет размер активной кисти / ластика от 1 до 500 px с шагом 3 px. Круг вокруг курсора показывает фактический диаметр мазка с учётом размера холста и масштаба выбранного слоя; он не попадает в экспорт. **3** — заливка, **4** — редактировать (перемещение, размер и поворот), **F** — дополнительная клавиша заливки, **M** — дополнительная клавиша редактирования, **K** — удалить выбранный цвет. Клавиши работают по физическому расположению, включая русскую раскладку; при вводе текста они не перехватываются.
- Меню **Форма кисти**: круг (по умолчанию), квадрат, спрей. Форма применяется также к ластику. Спрей распыляет точки, пока удерживается ЛКМ. **Разброс светлоты** (0–100%) делает отдельные участки рисунка светлее или темнее выбранного цвета; при 0% цвет неизменен. На ластик и заливку этот ползунок не влияет.
- Палитра серого: RGB (255,255,255), (200,200,200), (100,100,100), (50,50,50), (0,0,0). Выбор меняет цвет рисования и заливки; произвольный цвет по-прежнему доступен слева. Параметры кисти сохраняются в проекте.
- Рисование, заливка и ластик меняют только текущий кадр выбранного слоя. Другие кадры не наследуют рисунок автоматически.
- **Q** вставляет ключевой кадр после текущего и копирует текущий рисунок в независимый холст выбранного слоя.
- **A** вставляет после текущего пустой промежуточный кадр. Его собственных рисунка и ключа нет. Между соседними ключами A-кадр интерполирует положение, масштаб обеих осей, поворот и прозрачность; разные рисунки плавно растворяются друг в друге. Без двух соседних ключей рисунок A-кадра прозрачен. Редактирование превращает его в отдельный ключ.
- **Delete** удаляет текущий кадр или выделенный диапазон, сдвигая следующие кадры влево на всех слоях. В проекте остаётся минимум один кадр. Видео и звук остаются непрерывными источниками с привязкой к времени N/FPS.
- **Shift+ЛКМ** выделяет диапазон кадров от последнего обычного щелчка. Копирование и удаление работают с выделенным диапазоном; Q/A вставляют один кадр после текущего. Рисование работает только на текущем кадре.
- **Пробел** создаёт слой, **Backspace** удаляет выбранный слой. Воспроизведение запускается и останавливается кнопкой ▶ на шкале времени.
- **C** копирует выделенные кадры, **V** вставляет их начиная с текущего кадра выбранного слоя. Копируются рисунки, ключи и тип A-кадра; аудио и исходный видеофайл остаются на своём слое. Вставка заменяет содержимое кадров назначения; Z отменяет её.
- **Z** — отмена, **Y** — вернуть отменённое. Поддерживаются также Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z, Ctrl+C / Ctrl+V. История хранит до 20 последних изменений в текущей сессии.
- Стрелки — переход между кадрами, Shift+стрелки — выделение диапазона. Частота 1–60 FPS. Переключатель «Повтор» на шкале времени запускает анимацию с начала после последнего кадра, включая видео и звук. При включённом повторе конечные A-кадры плавно переходят от последнего ключа к первому ключевому кадру следующего цикла — по рисунку и всем трансформациям. Если перед первым ключом тоже есть A-кадры, переход продолжается через начало шкалы. С одним ключом A-кадры сохраняют его рисунок и параметры. Этот переход виден при выборе кадра, воспроизведении и экспорте. Настройка сохраняется в проекте; экспорт по-прежнему записывает один проход.
- В режиме **Редактировать** тяните слой для перемещения, боковые маркеры для независимой ширины, верхний / нижний — для независимой высоты, углы — для обеих осей, зелёный круг — для поворота вокруг центра слоя. В панели доступны отдельные поля «Ширина» и «Высота» (в процентах), а «Масштаб» меняет обе оси вместе. Предел масштаба 1000% снят: числовые поля и маркеры принимают большие значения. Кнопка замочка связывает значения ширины и высоты: при включении высота получает масштаб ширины, затем стороны изменяются одинаково при вводе чисел и перетаскивании. Замок сохраняется отдельно для каждого слоя в проекте; переключение можно отменить через Z/Y. Размеры обеих осей плавно интерполируются на A-кадрах. Маркеры автоматически размещаются внутри холста даже у увеличенного или смещённого слоя; при очень маленьком слое рамка управления увеличивается для удобства. Точные значения масштаба и угла доступны справа. Редактирование A-кадра превращает его в самостоятельный ключ. Полный оборот можно задать числом 360°; углы между ключами интерполируются как заданные числа.
- Кнопка **+** (или пробел) добавляет слой; стрелка поднимает слой; двойной щелчок по имени переименовывает его.
- Импорт PNG, JPG, WEBP, GIF, MP4, MP3. GIF импортируется статично. Поддержка видео и аудио зависит от кодеков браузера. Для MP4 шкала расширяется по формуле `ceil(длительность × FPS)`, максимум 600 кадров. Кадр с индексом N показывает видео в момент N/FPS, независимо от наличия ключа или типа A. Видео воспроизводится непрерывно; не декодируется целиком в картинки в памяти.
- **🎙 Записать звук** запрашивает разрешение браузера на микрофон. Повторное нажатие останавливает запись и добавляет отдельный звуковой слой (WAV), который сохраняется в `.animaster` и звучит при воспроизведении / экспорте WebM с начала проекта. Файлы не отправляются на сервер. Доступ к микрофону требует HTTPS или localhost. При отказе разрешите доступ в настройках сайта. Запись автоматически остановится при достижении предела шкалы — 600 кадров при текущем FPS.
- **Сохранить** открывает меню сохранения: «Сохранить в этом браузере» записывает текущий проект в IndexedDB; «Открыть сохранение» восстанавливает его после перезагрузки страницы. Хранится последнее ручное сохранение на этом сайте / устройстве; очистка данных сайта удаляет его. Автоматического сохранения нет.
- **↓ Проект** скачивает `.animaster` с рисунками, медиа, слоями, ключами и A-кадрами. **Открыть** восстанавливает скачанный файл. Этот же вариант доступен в меню «Сохранить».
- **↓ Анимация** открывает параметры видео. Нажмите «Создать видео · WebM», дождитесь окончания и нажмите **«↓ Скачать видео .webm»**. Перед скачиванием готовый результат можно просмотреть прямо в редакторе. Кнопка скачивания остаётся доступной для повторной загрузки до следующего экспорта / закрытия страницы.
- Экспорт PNG (текущий кадр) или WebM (анимация со звуком). Размеры 480×270, 960×540, 1920×1080. Качество меняет битрейт видео; PNG без потерь. При записи в реальном времени держите вкладку активной. Экспорт MP4 и анимированного GIF пока отсутствует.

При увеличении используется сглаживание высокого качества и плотность пикселей экрана. Неизменённые импортированные изображения рисуются из оригинала, без предварительного уменьшения до разрешения холста. Рисунки и отредактированные изображения остаются растровыми: увеличение не восстанавливает отсутствующие детали.

Значок `logo.svg` — SVG-интерпретация предоставленного рисунка, а не исходное изображение.

## Проверка

```sh
npm run check
npm test
```

Тесты проверяют интерполяцию ключей, границы заливки и удаление цвета. Проект не использует сборку, облачные API или секреты.

## Версия для Windows (.exe)

Переносимая сборка Windows 10/11 x64: `dist/ANIMASTER-0.1.0-Windows.exe`. Запускается двойным щелчком и открывает редактор отдельным окном с иконкой ANIMASTER. Для готового EXE не нужны Node.js, браузер, сервер или установка зависимостей. Настройки и сохранение «в этом браузере» в настольной версии хранятся в профиле приложения пользователя; для переноса проекта на другой компьютер скачайте `.animaster`.

Сборка из исходников (Node.js 22.12+):

```sh
npm ci
npm run build:win
```

Команда собирает самодостаточный HTML и Windows EXE со встроенной иконкой. При первой сборке требуется сеть для загрузки Electron и упаковщика; версии инструментов закреплены в `package-lock.json`. Значок собирается из `assets/icon.ico` (размеры 16–256 px); значок окна — `assets/icon.png`. Исходный рисунок в проекте представлен SVG-интерпретацией.

Запуск настольной версии из исходников на текущей ОС:

```sh
npx install-electron
npm run desktop
```

Настольная оболочка использует Electron, изолированный контекст страницы и отключённый Node.js в редакторе. Диалоги сохранения выбирают путь на устройстве. Разрешён доступ редактора к микрофону, доступ к камере не запрашивается.

EXE собран в Linux; формат Windows x64, ресурсы значка и встроенные файлы проверены. Запуск настольного редактора и сохранение проекта проверены на Electron для Linux. Непосредственный запуск готового Windows EXE в этой среде не проверялся. Сборка не имеет цифровой подписи издателя.
