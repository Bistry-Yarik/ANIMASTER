КИСТИ И ЦВЕТ

0% — ровный цвет. Выше — местами светлее или темнее.

Ножницы: нажмите на удаляемый цвет. У видео он удалится на всех кадрах, включая A-кадры. Допуск регулирует близкие оттенки.

ТРАНСФОРМАЦИЯ ◇

Редактировать (4): тяните слой для перемещения, боковые маркеры — для ширины, верхний и нижний — для высоты, углы — для обеих сторон, зелёный круг — для поворота. Изменения только на текущем кадре; A-кадры плавно соединяют ключи.
