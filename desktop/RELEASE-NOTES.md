# ANIMASTER 0.2.0

Редактор анимации для Windows 10/11 x64. В разделе **Assets** скачайте **ANIMASTER-0.2.0-Windows.exe** и запустите двойным щелчком. Node.js, сервер и установка зависимостей не нужны.

## Изменения

- Исправлено удаление выбранного цвета у видео: фон обрабатывается на каждом кадре, включая A-кадры, сохраняется в проекте и применяется при экспорте. Добавлена кнопка восстановления фона.
- Добавлены встроенные шаблоны «Карта мира», «Карта Европы», «Карта Африки» с границами стран. Карты работают без интернета и добавляются отдельными слоями. Данные Natural Earth, public domain.
- Добавлена настройка «Свободные углы»: каждый угол можно перемещать отдельно. Движение углов плавно интерполируется на A-кадрах и при повторе через конец анимации.
- Добавлена кнопка «Обучение» с шестью пошаговыми разделами.

Формат проектов `.animaster` сохранён; проекты версии 0.1.0 открываются в новой версии. Перед обновлением сохраните текущую работу.

Проверки: 18 модульных тестов и браузерные сценарии работы с видео, экспортом, углами, картами, обучением и сохранением проектов.

Сборка не имеет цифровой подписи издателя. Контрольная сумма файла находится в **SHA256SUMS.txt**.
