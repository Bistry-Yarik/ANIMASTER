# ANIMASTER 0.9.1

Windows 10/11 x64. Скачайте **ANIMASTER-0.9.1-Windows.exe** из Assets. Сохраните работу и закройте прежнюю версию перед запуском.

- **Новый логотип:** чёрно-белый глобус. Область вокруг глобуса прозрачная в PNG, ICO, окне приложения и интерфейсе.
- **Отражения:** в «Редактировать» голубая кнопка ↔ слева от рамки отражает по горизонтали, ↕ снизу — по вертикали. Рисунок сохраняет свой центр. Поддержаны группы кадров, A/AltA, отмена, сохранение и экспорт.
- **20 шрифтов:** меню «Шрифты · Aa» показывает каждый шрифт его настоящим начертанием. Восемь новых шрифтов встроены для работы без интернета: Lobster, Pacifico, Caveat, Oswald, Rubik, Russo One, Comfortaa, Amatic SC.

Проверены прозрачность иконки, отражения по обеим осям, сохранение, отмена, AltA и выбор встроенного шрифта. Контрольная сумма сборки — в SHA256SUMS.txt.
