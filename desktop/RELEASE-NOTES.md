# ANIMASTER 0.5.0

Windows 10/11 x64. Скачайте **ANIMASTER-0.5.0-Windows.exe** из Assets. Сохраните работу и закройте прежнюю версию перед запуском.

- **Деформация без белых треугольников:** непрерывное перспективное преобразование, включая полупрозрачные рисунки. Работает в просмотре, A-переходах и экспорте; есть программный вариант без WebGL.
- **Кадры без фиксированного лимита:** вставка, копирование, импорт и сохранение. Длинная шкала рисует только видимые ячейки, поле «К кадру» позволяет быстро перейти к нужной позиции. Ограничение записи микрофона по числу кадров тоже убрано.
- **1–240 FPS:** ползунок прилипает к 12, 24, 60 и 144; рядом кнопки этих значений. Числовое поле позволяет задать точный FPS.
- **Четыре новые карты:** Северная Америка, Южная Америка, Азия и Евразия. Всего семь офлайн-шаблонов с флагами, годами и кистью территорий.

Проверены отсутствие швов на полупрозрачном рисунке в ускоренном и программном режиме, проект на миллион кадров, навигация/сохранение, FPS и новые карты. Прежние проекты открываются. Скорость просмотра и видеоэкспорта зависит от устройства. Сборка без цифровой подписи издателя; SHA256SUMS.txt содержит контрольную сумму.
