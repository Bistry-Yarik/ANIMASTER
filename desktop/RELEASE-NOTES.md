# ANIMASTER 0.8.0

Windows 10/11 x64. Скачайте **ANIMASTER-0.8.0-Windows.exe** из Assets. Сохраните работу и закройте прежнюю версию перед запуском.

- **Новая иконка:** чёрно-белый объёмный AM по новому рисунку, в редакторе, окне и Windows EXE.
- **AltA:** Alt превращает A в опорный кадр кривой; N возвращает обычный A. Есть кнопка над шкалой. Видео/звук поддерживают AltA*.
- **Плавная траектория:** перемещение и деформация AltA направляют промежуточные кадры по кубической кривой, проходящей через опору без резкого перелома. AltA остаётся промежуточным и не превращается в Q при редактировании.
- **Заливка:** рисунок и цвет на AltA плавно меняются между ключами. Каналы независимы: заливка не изгибает движение, перемещение не меняет цвет.
- **Голубая линия пути:** видна при редактировании AltA, не входит в экспорт. Поддержаны несколько опор, повтор, сохранение, копирование, сдвиг кадров и отмена.

Проверены плавность скорости, углы, цвета и прозрачность, браузерные операции, сохранение и экспорт PNG, а также Alt в настольном Electron. Старые проекты открываются. Сборка без цифровой подписи издателя; SHA256SUMS.txt содержит контрольную сумму.
